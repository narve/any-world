# Rerunning the M1–M3 e2e specs overwrote committed milestone screenshots

- Severity: minor
- Area: e2e specs
- Status: fixed for M1–M3 in M4; M4 specs fixed in M5 (issues/M5-e2e-overwrites-m4-screenshots.md)
- Source: BUILD_LOG.md [M4/gate] e2e screenshot hygiene; Back-filled in M5 (shell fixer) from BUILD_LOG.md; the fix itself landed in M4.

## Evidence
During M4 the M2/M3 PNGs under docs/progress were regenerated by ordinary e2e reruns and showed up as modified
files.

## Fix
The M1–M3 specs write to test-results/shots/M* unless SHOTS_TO_DOCS=1; the regenerated PNGs were reverted.

## Regression tests
Manual: `git status` after an e2e run shows no docs/progress changes.
