# M3 — AI content: progress note

Date: 2026-10-24. Status: **exit check met.** There are 18 recorded worlds (14 written by agents acting as the provider, plus the 4 fixtures). They cover 18 genres, 3 of them in Norwegian bokmål, and 11 are non-violent. Every world validates, and every one can be picked and played in demo mode from the start screen, where the list is grouped by language. `content/prompts.json` holds 36 curated prompts; 18 of them have a recorded world. Bot simulations over 100 seeds per world and bot had 0 crashes and 0 stuck runs, and the explorer bot's win rate on normal was inside the band for every world. Typecheck, vitest, validate-worlds and Playwright are green.

## What was built

| Area | Where | Notes |
|---|---|---|
| Prompts | `src/llm/prompts/{world,gm,dialogue,common,schema-doc,world-schema,gm-summary}.ts` | The world prompt carries a condensed TypeScript-style World Spec description generated from zod (about 19k characters; the JSON Schema is about 110k). It also carries a creative brief, the engine's building blocks, generators, balance and validation rules, and a language rule. The GM prompt covers discipline, budget, add_rule limits, the help ceiling and a brief per hook. The dialogue prompt voices one NPC turn. All three are language-aware (§7b). |
| Generation pipeline | `src/llm/generate.ts`, `structured.ts`, `balance-worker.ts` | Validate, then repair (2 turns), then `finaliseWorld`, then `tuneWorld` (bots, in a Web Worker in the browser), then one balance-feedback turn. Errors are typed. |
| GM runtime | `src/llm/gm-runtime.ts`, `gm-checks.ts`, `client/ai.ts` | Async hooks. Every answer is dry-run through the engine, refusals go back to the model as repair feedback, the valid part of a bad reply is salvaged, and the offline director is the fallback. NPC voice works the same way. In demo mode, the recordings play once per moment. |
| Agents-as-provider tooling | `tools/print-prompt.ts`, `tools/agent-provider.ts`, `src/llm/situation.ts` | These use the exact prompts the game sends. Validation, balance analysis and recording go through the same code paths as the game. |
| Prompt library | `content/prompts.json`, `src/schema/prompts.ts`, `src/client/prompts.ts` | 36 prompts: 30 en and 6 nb, 35 distinct genres, 29 non-violent, 2 fantasy. 18 have a recorded world. The start screen's inspiration cards are drawn from the library, with prompts in the UI language first. A card in another language shows a language badge, and a world generated from such a card is written in the card's language. |
| Demo worlds | `src/client/main.ts`, `ui/components/screens.ts`, `ui/format.ts` | Every bundled world is listed in demo mode, grouped by language. Each group is labelled with the language's own name ("English", "Norsk bokmål") and a count, the UI language's group comes first, and each entry carries a `lang` attribute. |
| Clearer controls and goals, i18n foundation, mobile layout, renderer performance | see BUILD_LOG `[M3/client-ux]`, `[M3/renderer]`, `[M3/engine]` | Goal tracker, context action bar, onboarding card, slot explanations, the `t()` catalog, engine log keys, phone layout, quality tiers, and recovery from WebGL context loss. |

## Agents-as-provider: first-try validity and feedback

**First-try valid: 7 of 14 (50%).** All 14 validated by the third reply (7 on the first, 5 on the second, 2 on the third). What made the first reply fail:

| world | first-try failure |
|---|---|
| corporate-merger-kitchen | an unknownAppearances label over 40 characters |
| detective-sugar-hotel | an attack verb over 30 characters, then a misspelled terrain id |
| abstract-yellow-triangle | the shape `ico`, which is in the renderer but not in the schema, then a placeholder item id |
| folk-horror-scarecrow-wedding | tagline over 140 characters |
| heist-silent-vault | tagline over 140 characters |
| nb-troll-direktoratet | an item name over 40 characters |
| nb-russetid-bussen | a Norwegian attack verb over 30 characters |

Length limits caused 6 of the 7 first-try failures. Schema shape was never the problem.

**Feedback themes** (all 14 authors), with what changed:

| theme (authors reporting) | fix |
|---|---|
| Length limits are easy to miss (7) | VALIDATION now lists the limits that trip most often in one line: tagline, verb (with a note on long words in other languages), names, appearance labels, summary, labels, intro, events. The bokmål instruction adds a note on long compounds. |
| Engine facts had to be read from the source (10). The questions were what NPC roles do, how persuasion works, terrain density, how interact and onStand behave, what "guarded" means, how resource onEmpty works, the target of on_hit, factions, spawn_item, and items with a failed condition | BUILDING BLOCKS now states each of these: one line per NPC role (stock is ignored for other roles); persuade is not defeat (soft-lock rule); density > 0 gives at least one tile but no chosen spot, so use placedItems; onStand repeats every turn (never heal there); interact works from an adjacent tile and stays usable while its condition is unmet; guarded means within 2 tiles of the strongest hostile; onEmpty and on_resource_empty fire together, perTurn may be fractional, and a resource can be used in goal.lose; on_hit targets the other party; neutral actors do not fight; an item with a failed condition is still spent; spawn_item drops on the floor; keys use passive + passiveWhenCarried. |
| Kiters, guardians and turrets stall bots, and stun-lock bosses (8) | A behaviour pitfalls line: kiter param ≤ 2 and speed ≤ 90 or erratic, never on islands or in narrow tubes; pair guardians with chasers, and use an ambusher on a must-take item; prefer slow ranged chasers to turrets; stun, confuse and root need a cooldown ≥ 4. The boss is a chaser, not a guardian that waits. |
| First drafts far too easy (7) | BALANCE: 2 starting heals of 6–8, hpRegenEvery 8–12, boss hp 65–85 with summons capped, about one heal per three fights (terrain, healers and traders count), itemCount 5–8. |
| An alternative win route was trivial on arrival in the last area, or soft-locked after the boss was persuaded (5) | New BALANCE rule: every route must cost effort inside the last area and has its own gate. A persuadable boss means the other route must be guaranteed. Goal items must be placed or dropped, never only made by spawn_item. |
| No turn budget for clocks and deadlines (5) | "A run takes about 700–1100 turns (≈250 per area, the turn counter is global); size clocks to about 1.3× that; a resource clock is a timer, not damage." |
| Raw flag ids in the goal tracker, such as "kjopet hevet" (4) | **Contract addition:** `GoalSpec.labels` (flag or counter id to a player-facing name). The goal tracker uses it through `guide.ts stateLabel`. Labels were added to all 13 worlds with flag or counter goals, and a test checks that every recorded world labels them. The prompt asks for labels and for a goal.summary that names every route. |
| Backdrop colour meaning, and areas without a backdrop (2) | One line on each backdrop style (color is the dark base, color2 the stars or curtains), and every area gets a backdrop. |
| The shape example (an abstract painting) nudged the abstract-art request toward copying it (1) | The example is now a mundane brass weathercock and a cough drop. |
| Dialogue `trade` refused in play ("a choice is already open"), and recorded options not shown (6) | Trades in a conversation are now dropped (`gm-checks.ts dropTrades`) instead of costing the whole reply; 8 recordings contained them. agent-provider warns about them. The dialogue prompt says the game builds the buttons from the NPC's role and that trade must not be used. |
| GM snapshots: low_hp shown at full hp, death and victory shown as "playing" (6) | `situation.ts stateForHook`: low_hp puts the player at 25% hp, death sets lost and hp 0, victory sets won. agent-provider validates against the same snapshot. |
| The GM item pool leaked or mislabelled unknown items, e.g. a poison shown as "(heals)" (5) | Unknown items now read "(secretly …; never reveal)", and a heal with a harmful side effect is "mixed". The GM prompt forbids revealing either. |
| Instance ids in recordings do not replay across runs (4) | The GM and dialogue prompts prefer def ids for say, trade and change_faction. |
| Allowed actions per hook were unclear (3) | The GM prompt states that intro, death and victory allow only narrate, say and mood, which matches gm-checks. |
| The static analyser counted condition-gated or resource-clock rules as hp damage (4) | Condition-gated rule triggers are counted at `CONDITIONAL_SHARE` (0.3). |
| No pronoun register for bokmål (1) | The language rule now says "du" everywhere, unless the world's voice is formal, in which case "De" is used consistently. |

## Known issues (to M4/M5)

- **i18n is not complete.** UI strings and engine log lines are still English in nb worlds: the goal tracker ("Get …", "FINAL STRETCH"), context buttons ("Search", "Wait"), "Ask what they know", end-screen labels, and log lines such as "picks up". There is only an `en` catalog; `nb.ts`, the language picker content and translated library teasers are scheduled for M4. GM and dialogue snapshots also carry English engine log lines in nb worlds.
- **Recorded dialogue `options` are not shown.** By design, the engine's role options stay the player's buttons. The prompt now says so; showing the model's options as optional free-text replies is a possible M4 UX item.
- **The GM context `visible[].hp` is a percentage** while the NPC block shows absolute hp, which confuses the model. This should be labelled `hpPct` in a later engine pass.
- **Bots never take some alternative win routes.** On a tie, the planner prefers actor_defeated (heist, cyberpunk), so the balance verdict does not exercise the non-violent route. The routes were checked by direct engine scripts.
- **The cautious bot wins little in several worlds** (2–12%). This is acceptable under §2.5 (fun over exact balance), but M5 playtests should watch for friction from clocks.
- **The library does not seed "Surprise me" yet**: it still uses the genre × era × tone × twist draw. The library is used only for the inspiration cards.
- **The mobile HUD covers about 45% of a 390×844 screen** during play. That work is in M4 (§6b).
- **A static backdrop default is still missing**: an area without a backdrop gets a flat colour. The prompt now asks for a backdrop on every area, and the renderer default is an M4 item.
