# M1 — Foundation: progress note

Date: 2026-10-24. Status: **exit check met.** All three fixture worlds can be played in the browser, typecheck, unit and e2e tests are green, and screenshots are below.

## What was built

| Area | Where | Notes |
|---|---|---|
| Contracts | `src/schema/` (world, gm, refs), `src/engine/types.ts`, `src/llm/types.ts` | zod v4 World Spec + GM actions; cross-reference validator (`refs.ts`). Only optional, backwards-compatible additions were made during M1 (see BUILD_LOG). |
| Fixture worlds | `content/worlds/fixture-{ship,teen,western}.json` | 3 genres (generation-ship sci-fi, teen drama, weird western), 3–4 areas each, 13–14 actors, 24–25 items. `npm run validate-worlds` reports 3/3 valid. |
| Engine core | `src/engine/` (~7.7k lines) | Pure, seeded (sfc32): energy turns, movement, melee/ranged combat, all Effect types and targeting shapes, statuses/flags, triggers, monster AI, inventory and use modes (consumed/charges/reusable/passive, equip, cooldowns, durability), item knowledge (unknown → vague → clear), progression/perks, areas and transitions, NPC verbs (talk/trade/persuade), GM actions with budget, symmetric shadowcasting FOV, A*/BFS, describe* views, legalActions, save/load. |
| Mapgen | `src/engine/mapgen/` (~2.1k lines) | Generators: rooms, caves, maze, open, town, building, ship, arena. Finalize step guarantees connectivity and that the start and exit can be reached. ASCII dump tool: `tools/mapgen-ascii.ts`. |
| Renderer | `src/client/render/` | three.js r186: orbit camera that rotates in 90° steps, tiles, archetype models, lighting/fog tied to the engine's sight radius, wall cut-away (wedge plus per-actor sight lines), instanced static terrain, HP bars, tweens and vfx, picking. Dev pages: `/dev/area.html`, `/dev/gallery.html`. |
| UI shell | `src/client/ui/` | HUD (stats, resources, rules panel), log, hotbar, backpack with action menu, inspect/tooltips, dialogue, trade, level-up/perk choice, GM choice, narration cards, start/end screens, toasts. All labels come from the world's vocabulary. |
| Integration | `src/client/{main,session,game-controller,boot,travel,storage,view,invalid}.ts` | Pure `GameSession` plus a controller that connects engine, renderer and UI. Click-to-travel, camera-relative keys, autosave/resume, `?world=&seed=` links, demo worlds on the start screen. |
| LLM layer | `src/llm/` | Anthropic and OpenAI-compatible providers, presets (including non-US providers), structured output with validate/repair/retry, mock provider and recordings, direct and backend transport, timeouts and retry budget. |
| Server | `server/` | Serves the client, `POST /api/llm` proxy (keys come from env), `/api/presets`, rate limit (proxy-aware XFF hop count), closed model allowlists. |

## Test results (final gate run, 2026-10-24)

- `npx tsc --noEmit -p .`: **0 errors**
- `npx vitest run`: **40 files, 545 tests, all passing**. The suites are engine (10 files, including a 500-step fuzz test on each fixture), mapgen (3), schema (1), llm (10), server (3), client (5), ui (5) and review repros (2), plus render tests next to their code.
- `xvfb-run -a npx playwright test`: **25/25 passing**. They cover gallery and area renders per fixture, animations/camera/picking, HP bar draw order, cut-away, actors in dark areas, start screen → demo run, direct links with camera-relative keys, mouse travel and the backpack, NPC dialogue, and end screen → replay. No console errors.
- `npx vite build`: OK (one chunk-size warning, more than 500 kB, from three.js).

The final gate itself fixed the last 4 open review repros (issues/M1-item-cooldown-off-by-one.md, issues/M1-unknown-item-leaks.md):
- An item cooldown of N now blocks the next N turns. Consumed stacks keep their cooldown.
- `spawn_item` effect lines no longer reveal unknown items.
- Fallback appearances for unknown items are unique.

All 31 files in `issues/` are now `fixed`.

## Playtesting

Over three playtest rounds, all three fixtures were won end-to-end in the browser (round 3, bot plus HP top-ups). The bugs found along the way are all recorded and fixed in `issues/`: soft-locks, knowledge leaks, a shooter on an unseen diagonal, actors not drawn in dark areas, reload wiping the run, toast pile-up, narration covering the player, and others.

## Known issues / carried into M2

- **Log spam from per-turn damage**: in the western, repeated lines like "Dolores Aguila takes 1 Heat." fill the log, and damage without a type logs as "takes 1." Merge repeated lines the way the toasts already do, and name untyped damage after the source.
- **HUD truncates longer resource names** ("Batt…", "Rou…") in the stat panel. A wider label column or a tooltip is needed.
- **Unknown-item fallback labels** are lowercase adjective+kind ("strange flask"). That works, but the world should provide `unknownAppearances` pools so the labels have flavour.
- `npm run sim` points at `tools/sim.ts`, which does not exist yet. Bots and balance are M2/M3 scope.
- The prologue narration card shows a scrollbar while its text types out (cosmetic).
- The bundle is one chunk of more than 500 kB (three.js). Code splitting is left for M4.
- The M2 backlog in PLAN.md is unchanged: non-Earth-like generators/backdrops, GM-invented rules.
